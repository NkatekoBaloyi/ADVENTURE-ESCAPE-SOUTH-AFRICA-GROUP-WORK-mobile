# Escape Adventure SA — Mobile Application

A professional, production-ready React and TypeScript mobile application built for **Escape Adventure SA** in **Cape Town, South Africa**[cite: 2].

---

## Overview

This application delivers a fully interactive mobile experience styled with **Tailwind CSS**. It follows a custom design system featuring warm cream backgrounds (`#FAF8F5`), deep forest green branding (`#0A2F1D`), and warm gold accents (`#D99B00`) tailored for immersive escape room adventures.

---

## Features & Screens

* **Home Dashboard**: Features brand headers, quick search access, trust badges (safe & hosted, 4.9 guest rating, made for teams), and featured rooms like *The Lost Temple*[cite: 2].
* **Rooms Explorer**: Browse immersive rooms with theme filters, difficulty ratings, durations, and pricing starting from R320 per player[cite: 3].
* **Interactive Booking Flow**: A seamless 3-step checkout experience covering:
  1. **Choose Time**: Calendar selector, time slots (e.g., 11:00 AM, 01:00 PM, 03:00 PM), and dynamic player count adjustment[cite: 4].
  2. **Review**: Summary of date, time, player count, total pricing in ZAR, and 15-minute early arrival instructions[cite: 5].
  3. **Payment**: Secure card and instant EFT payment simulation.
* **Adventure Tickets**: Digital ticket view containing admission details, booking references (e.g., `EA-2026-1024-7731`), venue address (`123 Adventure Street, Cape Town`), and a decorative QR-style graphic[cite: 8].
* **My Bookings**: Dedicated tabs for managing upcoming and past adventures with quick ticket access[cite: 6].
* **Notifications**: Stay up to date with adventure reminders, booking confirmations, and payment receipts[cite: 7].
* **Profile**: User explorer profile, personal information management, and direct customer support links.

---

## Tech Stack

* **Framework**: React with TypeScript
* **Styling**: Tailwind CSS
* **UI Design**: Mobile viewport container (393px × 852px frame) with smooth micro-interactions, active scaling, and responsive modal transitions.

---

## Getting Started

1. Copy the TypeScript component code into your React project (e.g., `EscapeAdventureApp.tsx`).
2. Ensure Tailwind CSS is installed and configured in your project.
3. Import and render `<EscapeAdventureApp />` inside your root component or page.
